# MASTER PROMPT 2.1 — RARITETBOOK.RU (Техническое задание)

**Масштабируемая открытая цифровая библиотека на 10 000–50 000 книг**

- **Автор и основатель:** Денис Омельчук (`https://omelchukdenis.ru`, Telegram: `https://t.me/omelden_site`)
- **Домен:** `https://raritetbook.ru`
- **Тип:** Open Digital Library / Digital Historical Archive
- **Цель:** Создать полноценную бесплатную цифровую библиотеку старинных, редких и классических произведений с возможностью масштабирования до 50 000 книг.
- **Главный принцип:** Читать бесплатно, без рекламы и без обязательной регистрации.

---

## 1. Позиционирование и тематика

- **Название:** RaritetBook
- **Основной слоган:** «Старинные книги. Вечные знания»
- **Дополнительный слоган:** «Читай. Узнавай. Сохраняй историю»

**Ключевые категории и направления:**
1. История России и Российская империя (летописи, труды историков, архивные документы, мемуары).
2. Русская классика (проза, поэзия, драматургия XVIII – начала XX вв.).
3. Старинные русские учебники и педагогика (дореволюционные гимназические курсы, арифметика, словесность, логика).
4. Наука и философия (труды русских и мировых учёных, естествознание, география, этнография).
5. Зарубежная классика и готическая литература (в дореволюционных и перешедших в общественное достояние переводах).
6. Кавказ и народы России (история, этнография, нартовский эпос, осетинская и кавказская классика).
7. Редкие дореволюционные издания.

## 3. Технологическая архитектура и масштабирование (10 000–50 000 книг)

Подход: **Static-First + Serverless + Object Storage (S3-совместимый)**.

- **Frontend:** React + Vite + TypeScript + React Router + модульный/структурированный CSS. Хостинг на **Cloudflare Pages** (CI/CD из GitHub). Книжный фонд в GitHub на продакшене не хранится.
- **Object Storage (Cloudflare R2):** хранение `original.fb2`, оптимизированных `book.json`, `cover.webp` и индексов каталога (`catalog.json`, `categories.json`, `authors.json`). Раздача через CDN **без обращения к D1**.
- **Backend (Cloudflare Workers):** регистрация, авторизация (безопасные cookie-сессии, хеширование паролей с солью, CSRF, rate limiting), синхронизация прогресса, закрытый админ-импорт.
- **Database (Cloudflare D1):** исключительно таблица `users` (один пользователь — одна строка, `progress` в JSON до 10 КБ, редкая синхронизация с debounce 3–5 мин, dirty-state и сохранением при скрытии вкладки). Тексты книг в D1 не хранятся.

### Структура хранения в архиве / R2
```text
archive/
  books/
    <author-slug>/
      <book-slug>/
        original.fb2
        book.json
        cover.webp
        meta.json
  catalog/
    catalog.json
    categories.json
    authors.json
  images/
    categories/
    backgrounds/
    covers/
```

## 4. Утверждённые продуктовые расширения (v2.1)

1. **PWA и офлайн-чтение (Service Worker + IndexedDB):**
   - Открытая пользователем книга (`book.json` + обложка) автоматически кэшируется в `IndexedDB`.
   - Читатель может продолжать чтение без интернета (в дороге, самолёте, горах), а повторные открытия не расходуют операции чтения R2.
2. **Мгновенный поиск в Web Worker на базе `MiniSearch`:**
   - Вместо блокировки основного потока используется `MiniSearch` внутри Web Worker по компактному индексу метаданных (рассчитано на 10 000–50 000 книг).
   - Кастомная нормализация: регистронезависимость, эквивалентность `е/ё`, поддержка осетинских символов (`ӕ`/`æ`), поиск по названию, альтернативному названию и автору + кнопка быстрой вставки `ӕ` в строке поиска.
3. **Генератор карточек цитат в один клик:**
   - При выделении фрагмента текста в читалке можно в один клик сгенерировать эстетичную карточку «под старинную бумагу» с цитатой, автором, названием книги и аккуратным знаком `RaritetBook.ru` для скачивания или пересылки в Telegram.

## 5. Импорт FB2 и формат данных

Полноценный конвейер проверки и конвертации FB2 / ZIP(FB2) → `book.json` с сохранением:
- структуры глав и оглавления (а также чанкинга для особо крупных томов),
- абзацев, подзаголовков, эпиграфов, стихотворных строф, курсива, полужирного начертания, сносок и проверенных иллюстраций.

## 6. Ключевые маршруты и функциональность

- `/` — Главная: Header, Hero («Старинные книги. Вечные знания»), 6 карточек категорий, книжные полки («Новые поступления», «Продолжить чтение», «Рекомендуемые книги»), блок о проекте. Никакой выдуманной статистики.
- `/catalog` — Каталог с фильтрами (категория, язык), сортировкой, пагинацией и поиском через Web Worker + `ӕ`.
- `/book/:slug` — Карточка книги: обложка, годы написания и издания, язык, категория, историческая справка, описание, источник, юридический статус (ст. 1281–1282 ГК РФ), кнопки «Читать онлайн» и «Скачать FB2».
- `/read/:slug` — Онлайн-читалка: темы «Старинная бумага» (по умолчанию), «День», «Ночь»; размер шрифта 14–24 px, интерлиньяж, ширина колонки, выбор шрифта (с засечками / без), оглавление, точный процент и позиция, закладка, генерация цитаты, мобильная нижняя панель.
- `/about`, `/author`, `/auth`, `/privacy`, `/terms` — Информационные и правовые страницы, страница об основателе проекта Денисе Омельчуке (без вымышленных регалий).

## 7. Юридическая чистота, Кэширование, SEO и Производительность

- **Правовой контроль (ст. 1281 и 1282 ГК РФ):** публикация только произведений в общественном достоянии (проверка года смерти автора **и переводчика** — не менее 70 лет, либо 74 лет для участников/тружеников ВОВ; учёт прав на иллюстрации и современные комментарии). Для каждой книги фиксируются источник, год издания, переводчик и правовое основание.
- **Кэширование:** книги и ассеты — `Cache-Control: public, max-age=31536000, immutable` (с версионированием); каталог — `public, max-age=3600, s-maxage=86400`; API аккаунтов — без публичного кэша.
- **SEO и качество:** уникальные мета-теги, Canonical, Open Graph, `Schema.org/Book`, `sitemap.xml`, `robots.txt`, адаптивность от `320px` до `1920px`, целевые метрики Lighthouse **90+** по всем четырём категориям.
